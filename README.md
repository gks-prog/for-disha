# For Disha ♡

A soft, floral birthday microsite featuring an Instagram Reel video preloader (`DO2btgSk07n`) that opens after the reel finishes playing, continuous floating flowers and subtle margin doodle art, a windy clothesline polaroid gallery with wooden clips, an organized hand-illustrated SVG & doodle-art virtual bouquet with unwrap choreography, GSAP motion, and an interactive 4-frame corner guinea pig companion.

## Deploy with GitHub Pages
1. Create a new public repository (e.g., `for-disha`).
2. Upload all files and the `assets/` folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
